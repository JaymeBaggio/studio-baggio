## Page Design Direction

Do:

- Use the existing Studio Baggio visual system: Aileron, quiet monochrome, sharp editorial spacing, hairline rules and restrained emphasis.
- Keep the article shell consistent across every piece.
- Use `700` bold only for deliberate inline emphasis, thesis lines, CTAs and key definitions.
- Use Studio Baggio-style evidence blocks where they make the argument easier to scan, especially for proof, frameworks, definitions and examples.
- Build simple native SVG/info graphics for concepts that need structure, using the locked neutral palette and hairline grammar.
- If the Firecrawl article needs Firecrawl orange, treat it as content-specific evidence inside that article only; do not let it become a site-level accent colour.
- Add `Originally appeared in Rough Cut RCX` metadata where helpful, but do not make the page feel like a Rough Cut issue archive.

Do not:

- Reuse Rough Cut PDF/Substack layouts.
- Publish four unrelated articles on one page.
- Make the index a generic blog-card grid.
- Wrap full article pages in heavy card containers.
- Use SaaS cards, bento grids, glassmorphism, rounded feature tiles, drop shadows, blobs, gradients, warm editorial palettes or new type roles.
- Over-design every paragraph; the default reading experience should still be calm and editorial.

Suggested article components:

- `ArticleHero`: category, date, source issue, H1, dek and primary thesis line using existing title/body/label roles.
- `ArticleBody`: full article text with Studio Baggio typography.
- `InsightCallout`: ruled argument block for memorable lines, not a decorative card.
- `EvidenceBlock`: compact proof/stat/example block using hairlines and neutral surfaces.
- `ProcessDiagram`: native SVG or CSS diagram for workflows like Firecrawl, built in the Studio Baggio system.
- `ComparisonBlock`: restrained two-column comparison for old model vs new model.
- `RelatedInsights`: 3-5 contextual internal links using ruled rows.
- `CommercialNextStep`: quiet CTA to relevant Studio Baggio work.

Visual constraints:

- Aileron only.
- Font weights only `400` and `700`.
- Colours only the locked neutral tokens plus approved blue usage.
- No new colour accents unless Jayme explicitly approves them.
- No card-in-card layouts.
- No horizontal overflow.
- Article reading copy should stay below roughly 65-75 characters per line on desktop.
- Mobile article pages can scroll naturally but must keep proper side padding and avoid clipped headings, rows or diagrams.
